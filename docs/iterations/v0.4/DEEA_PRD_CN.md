## 用户问题与范围
跨篇计数需要可信的词形归并、可恢复的作文历史和可立即核查的原句。本版解决“保存 → 找词 → 看原句 → 备份恢复”的流程。用户要求同时模拟约 IELTS 4–5、5.5–6.5、6.5–7.5 分学生及教师；这些是任务设计假设，不是对样本文本的评分。

## 已实现与验收
| 能力 | 可观察行为 |
| --- | --- |
| 归并修正 | adding 不再归到 ad；add/added/adding、write/wrote/written、take/took/taken 等按明确规则归并；保留观察词形。 |
| 原句核查 | 单篇点击词语得到逐句证据与高亮；跨篇点作文标题直接打开目标词的句子及全文高亮；返回后保留展开词条。 |
| 低次数入口 | 默认 ≥3 次；可显示全部分析词，或用基本形式及原文词形搜索。搜索包含 1–2 次的词，不改变计数。 |
| 备份与导入 | 导出 JSON；选择文件后先显示新增、重复、重名数量及标题预览；确认后合并，取消不写入。原记录不被同名/同 ID 的不同内容覆盖。 |
| 故障保护 | 历史损坏与无历史分开显示；损坏或存储不可访问时暂停保存。损坏原始内容可下载，确认恢复前另存到浏览器独立键；保存失败保留原键。 |
| 连续使用 | 保存成功后可“写下一篇”，保留已保存历史；三篇建议可展开；中英文输入标签、词形解释及具体的语义误读示例。 |

备份导入保留作者自带标题和日期。同标题不同正文会改名保留，导入不等于编辑修改稿。只放同一写作者的同类任务，跨篇仍使用全部历史；练习提示仍只用最近三篇。

## 模拟走查与结果
[体验记录](./USABILITY_REVIEW_CN.md)记录四种角色、三轮任务及修正。素材是原创、未评分的短文切片，另保留原有五篇完整作文的自动回归。没有真实学生访谈、教学干预或学习效果测量。验收对象是能否找到原句、核对次数并恢复数据，不是词汇质量或 IELTS 分数。

## 边界与下一步
本版不新增自动语义判断、评分、AI 建议、教师批注持久化、目标追踪、作文版本编辑、作者隔离或比较范围筛选。低水平用户仍需要教师帮助解释“具体影响”；较高水平用户仍需要搭配、语义和论证层面的人工判断。下一步优先对真实用户验证原句任务，再考虑可保存的练习目标与修改稿关系。
