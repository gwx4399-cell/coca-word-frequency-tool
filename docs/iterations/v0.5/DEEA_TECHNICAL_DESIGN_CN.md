# DEEA v0.5 技术设计

日期：2026-11-03 至 2026-11-04（Asia/Taipei）。状态：分支已实现；[草稿 PR #10](https://github.com/gwx4399-cell/coca-word-frequency-tool/pull/10)，未合并或部署。

## 数据与持久化

保留 `deea.essays.v1` 的数组容器以兼容现有原文。读取不迁移、不改写。EssayRecord 增加可选 `learnerId`、`genre`、`taskId`、`draftKind`、`revisionOf` 与 `notes`。基础形式不带这些字段的旧记录仍有效，展示为未分组。

教学判断包含原文 UTF-16 起止位置、原句快照、判断类别、理由、可选 lemma 和创建/更新时刻。可选 goal 包含目标、练习、归档状态和 checks。check 关联后续作文，包含人工状态、原句锚点、理由及学生反思。正文不可原位修改；修改稿是关联父稿的新记录，因此原有锚点不会因编辑漂移。

所有相关记录使用同一个 localStorage 数组写入，避免多键半成功。容量不足时 setItem 抛错，已有原文及教学数据保持原样。损坏历史沿用 v0.4 的暂停写入、原始数据下载和确认恢复前留存机制。跨标签备份预览在确认时检查原始序列化快照是否改变。

## 图与证据校验

`storage/teachingValidation.ts` 验证：父稿必须存在、无环、同学生/文体/任务，修改日期不早于父稿；教学锚点必须精确匹配原文；检查必须关联同一学生的后续修改稿或独立任务；新任务成功状态不能用于修改稿或同任务名称。未知状态、重复 ID、悬空引用、伪造引文和非法结构整批拒绝。

“没有适用机会”允许不提供引文，但理由必填。“仍需练习”及两种正向状态需要原文证据。状态由人选择，程序没有机会识别或学习效果判断。通过身份、日期和类型校验不等于验证独立完成或因果迁移。

按任务族更新学生/文体/任务，修改稿保留其 revision 类型。已关联检查若因此跨学生或失去类型依据，则阻止更改。父稿、被检查的文章、含后续检查的目标源稿不能删除；保留证据优先，界面说明原因。未关联的普通作文沿用确认删除。

## 导入与导出

备份格式仍为 `deea-essay-backup`，新导出 version=2，接受数字 1 或 2。先校验整份图；按父稿优先顺序去重和分配 ID；完成映射后重写 revisionOf 与检查 essayId。不同学生不按相同正文合并。同一学生的标题冲突改名保留。教学判断按内容去重，同 ID 的不同判断另存版本并在界面提示；再次导入同一版本不重复添加。备份包含所有学生，而反馈单仅限所选学生/任务。

TXT 批量读取先完成全部校验，再复用备份预览及单次确认写入；空英文、编码替换符、错误扩展名或超限会阻止本批导入。文件名提供标题/任务名，用户给定学生、文体与共享日期。演示材料也是版本化备份，不自动注入历史。

HTML 反馈单通过 `teaching/report.ts` 生成，所有用户字符串转义，不内嵌脚本或外部资源。当前任务导出包含整个修改族的判断；目标页导出当前学生活跃目标。使用 A4 打印样式，篇幅较长会分页；不是保证单页的 PDF 生成器。

## 分析规则

`teaching/workflow.ts` 按学生和文体筛选，再按 taskId 或修改族分组，取最早原稿或最新末端稿；手动排除后供跨篇分析及最近三篇提示共用。跨篇候选仍需至少两篇、累计三次。每百词频率=词条次数/全文 token 数×100，仅作为篇幅背景。比如同任务三个版本默认只算一个任务；没有学生或文体时不生成跨篇统计。计数下降、题目更换和目标词消失不推断进步。

新增 UI 分在 ComparisonScope、TeachingPanels、BatchImport；原句分段共用 evidence.ts，未新增依赖。测试环境显式绑定 jsdom 的 localStorage，避免 Node 原生 Web Storage 影响浏览器测试。

## 验证与限制

Node 22 下运行 `npm test`，71 项/13 文件通过；`npx tsc --noEmit` 通过；`npm run build` 生成生产文件，仍有原有 COCA CSV 带来的大包提示。主要新增检查覆盖不同学生同标题、范围/版本排除、不可伪造的锚点、目标限额、人工核查状态、ID 冲突重映射、冲突判断、旧备份、非法关联、容量失败、TXT 原子导入和 HTML 转义。

具体浏览器证据见[体验记录](./USABILITY_REVIEW_CN.md)。未检验真实移动硬件、辅助技术、超大作文集或长期课堂效果。存储仅限浏览器来源，不提供账号隔离、同步或访问控制；清理站点数据前需要外部备份。
