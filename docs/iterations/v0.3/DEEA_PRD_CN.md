# DEEA v0.3 产品需求文档（中文）

**状态**：在 `feature/across-essay-pilot-v0-3` 分支实现，待评审与合并。**日期**：2026-09-23。  
**版本主题**：跨篇统计基础 + 一个受限的“重要性”词组试验。此版本仍是本地规则原型，未接入 AI。
**关联 PR**：[v0.3 跨篇统计与词组试验 #6](https://github.com/gwx4399-cell/coca-word-frequency-tool/pull/6)。

## 1. 问题、目标与节奏

v0.2 能在保存三篇后给出少量提示，但单篇明细仍列出大量只出现 1–2 次的词；“跨篇”仅是八个预设词在最近三篇中的计数，不能成为以后设置目标与观察变化的通用数据基础。本轮用户希望隐藏单篇低次数词、实现真正的跨篇汇总，并谨慎试一次意群统计。

本次选择**先建可复用的全历史统计，再试一个人工词组**。这控制了迭代速度：不引入整套自动意群数据库，也不提前推出“表达依赖”诊断。

## 2. 本版交付与验收

| 用户可见功能 | 规则 / 可观察结果 | 验收 |
| --- | --- | --- |
| 精简单篇词表 | 总词数保留；lemma 表格只显示在本篇出现 ≥3 次的词，保留 observed forms 与次数。 | 一篇中出现 1、2 次的词不占表格行；内部分析不丢失它们。 |
| 新增 Across essays 视图 | 对当前浏览器**全部已保存作文**按 lemma 汇总；仅显示至少出现在两篇且累计 ≥3 次的词。 | 逐词给出出现篇数 / 总篇数、累计次数；展开后见每篇标题、日期、次数、词形并可打开原文。 |
| 低次数计入跨篇 | 例如某词在三篇各出现一次：单篇表格均隐藏，但跨篇显示 3/3 篇、累计 3 次。 | 低次数记录参与分子，不被 UI 筛选误删。 |
| “重要性”试验组 | 只比较 `important / significant / essential / crucial` 这四个配置词。组内总次数 ≥3 且至少涉及两篇时，显示出现最多的词在**这四个词的观测次数**中所占比例；成员明细可展开。 | 4/6 = 66.7% 等比例可重算；0 次或证据不足不显示百分比结论。 |
| 三篇建议微调 | 原有建议仍只看最近三篇；弱复现提示至少累计 3 次。 | 1+1=2 次的词不以独立词卡出现；无合格词时保留一般练习提示。 |

“跨篇统计”与“三篇写作建议”是两个窗口：前者为全部历史作文提供基础数据，后者仍是最近三篇的轻量教学提示。删除作文后两者都从剩余原文重新计算；无需新建账号或迁移既有记录。

## 3. 页面与使用路径

一级导航新增 **Across essays / 跨篇统计**，与 New essay、History 并列。用户在跨篇表格点开一个词，可逐篇查看其出现次数；点击作文标题返回 History 的原文详情。试验组显示一个组内比例和可展开的成员次数，界面始终解释其分母。没有达到门槛时展示证据不足提示，不显示 0% 或“没有依赖”。

单篇表格若没有任何 ≥3 次的词，明确说明低次数仍进入跨篇计算。用户仍可在 History 看完整原文和写作题目，核查不同题目是否造成某词自然重复。

## 4. 分母和解释边界

组内占比的公式是：

```text
某成员出现次数 ÷（important + significant + essential + crucial 的出现次数）× 100%
```

例如三篇里 `important ×4`、`significant ×1`、`essential ×1`、`crucial ×0`，则在**预设四词组**中 important 占 4/6 = 66.7%。它**不是**“所有表达重要性的机会”中使用 important 的比例：作者可能用别的短语表达重要性，也可能以不同词性或含义使用这些词。超过 50% 只是一条待核查线索，不能据此称为意群依赖或学习水平下降。

当前代码没有议论文文体标签，也无法区分多个写作者。因此跨篇视图会汇总该浏览器的全部作文；演示应由同一写作者输入同类议论文。未来做严格比较时必须引入文体、题目及人工语义核查。

## 5. 评估与下一步

**本轮工程验收**：测试低次数隐藏而累计仍正确、跨篇逐文证据、删除后的重算、试验组分母为零、标题跳转；类型检查与构建通过。通过这些测试只能证明软件按规则计算，不能证明教学有效。

**可复现样本**：补充[五篇原创 IELTS Task 2 议论文](../../../data/demo/IELTS_TASK2_FIVE_ESSAYS.md)，用于逐篇录入并核查“低次数隐藏 / 跨篇保留 / 四词组分母”。[产品设计图](./DEEA_PRODUCT_DESIGN_CN.md)用五篇作文的真实计算结果绘制已实现页面。样本未预置到用户历史，也未经雅思评分；本版未新增自动导入功能。

**下一轮用户验证**：找教师或学习者用几篇真实议论文核查：跨篇高频词是否由题目要求造成；四个预设词是否真的在可替代的语义位置；能否从表格回到原句并形成一个练习目标。记录误判实例再决定是否扩展词组。

**范围外**：完整意群机会标注、上下文词性识别、AWL/UWL、自动 AI 建议、正式词汇目标、目标后 +1/+3/+5 维持/回归判断、班级与同步。现阶段跨篇计数只是这些功能的数据基础。
